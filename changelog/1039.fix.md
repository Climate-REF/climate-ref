Fixed executions recording the wrong input datasets when obs4MIPs data was filled in from obs4REF, which could list unrelated CMIP6 datasets on an execution. Releases v0.18.0 to v0.20.3 are affected when obs4REF data has been ingested, and upgrading does not correct executions that already exist. To repair them, back up the database and run [`scripts/repair-execution-datasets.py`](https://github.com/Climate-REF/climate-ref/blob/main/scripts/repair-execution-datasets.py) with the climate-ref version that produced the executions, either before or after upgrading. It is a dry run unless given `--apply`, and holds the `ref solve --lock` lock while it runs.
