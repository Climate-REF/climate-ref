Every file an execution writes is now copied to the results directory, also when it fails, so the logs and partial outputs show how far it got.
Symlinks to input data are not copied, and providers can exclude large intermediate files: ESMValTool leaves out preprocessed data and `resource_usage.txt`, PMP leaves out the inputs it joins for ENSO.
A successful execution whose provider is not installed where its result is handled is now marked as failed.
