Removed `ConvertedCMIP7Request` (`climate_ref_core.esgf.cmip7_converted`), which built CMIP7 test data from CMIP6 data.

Removed `climate_ref_core.cmip6_to_cmip7` and with it the conversion of CMIP6 data to CMIP7 and the bundled CMIP7 Data Request mappings (`DReqVariableMapping`, `get_dreq_entry`). ILAMB diagnostics now name the CMIP7 branded variable of each model variable in `CMIP7_BRANDED_VARIABLES`, and fail to load if one is missing.
