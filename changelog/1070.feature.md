Test cases can now be marked as expected to fail with `TestCase(xfail="reason")`, e.g. while no matching data is published. `ref test-cases fetch --strict` then tolerates their data not being found, `mint`, `run`, `replay` and the CI gate skip them, and their regression tests are marked as strict `xfail`. When data resolves for such a case that has no committed catalog, `ref test-cases fetch` reports it, and fails with `--strict`, so the mark can be removed.
