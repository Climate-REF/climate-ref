Compresses Celery task and result message bodies with gzip by default.

Message bodies are dominated by the datasets DataFrame carried in the execution definition,
and results hold that same definition for `result_expires`.
Both shrink by roughly 80%, which cuts broker memory on a full solve.
Override with `CELERY_TASK_COMPRESSION` and `CELERY_RESULT_COMPRESSION`,
or set either to an empty string to disable.
