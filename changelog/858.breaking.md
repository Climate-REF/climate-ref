Removed the `ref test-cases build` and `ref test-cases sync` commands.
`build` is now `ref test-cases run --from-slot`,
which rebuilds the committed bundle from the native already in the output slot without executing.
`sync` is no longer needed because `replay` warms the same store cache when it materialises.
The `NativeStore` protocol and its three implementations
(`LocalFilesystemStore`, `PoochReadStore` and `R2WriteStore`) were also replaced
by a single `NativeStore` class built from the store URL.
