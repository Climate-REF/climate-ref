Peak memory is now measured over the execution's own process tree unless the executor
declares that the execution has its cgroup to itself.
A cgroup reading covers every process in the container, which is only what an execution
used when nothing else is running there.
Both figures are kept in `resource_context`, under `cgroup_peak_bytes` and `proc_tree_peak_bytes`,
so a large gap between them shows when a container was shared.
