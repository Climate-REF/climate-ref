Updated the PMP provider to `pcmdi_metrics` 4.2.1, up from 3.9.2.
The extratropical modes of variability diagnostics now run roughly 40x faster
because the variability modes analysis chunks its SVD (singular value decomposition).
The new release also corrects the modes of variability linear regression, the spatial statistic masking
and the latitude ordering, so the variability modes metrics and the annual cycle `ta` metrics change.
