Updated the PMP conda environment to `pcmdi_metrics` 4.2.1, `enso_metrics` 2.0.0 and Python 3.12.
The extratropical modes of variability diagnostics now run roughly 40x faster
because the variability modes analysis chunks its SVD (singular value decomposition).
The jump from `pcmdi_metrics` 3.9.2 also corrects the modes of variability linear regression,
the spatial statistic masking and the latitude ordering,
so the variability modes metrics and the annual cycle `ta` metrics change.
`enso_metrics` 2.0.0 breaks the ENSO feedback metrics on partial calendar years,
so the fix from CLIVAR-PRP/ENSO_metrics#98 is installed over the top until it is released.
Provider pip packages are now installed with `--force-reinstall`,
because pip skipped the override when the conda package reported the same version.
