Added `ref test-cases diff`, which renders the regression baselines changed on a branch as a local HTML report.
Images are shown old and new side by side, with a button that overlays them.
Text outputs get a coloured diff, and NetCDF and other binaries are listed with a size delta and a link to each blob.
Pass `--html-dir` to choose where the report is written, and `--no-fetch` to skip blob downloads and report sizes only.
