A changed `.nc` file in the `ref test-cases diff` report now shows what moved inside it.
Each file gets a collapsible listing of its ncdump-style header and a table with one row per
data variable carrying min, max, mean, NaN count, the largest absolute and relative difference,
and the number of cells that differ.
The header listing keeps every line and marks the ones that moved, so it doubles as a
description of the file, and a toggle reads the two sides next to each other instead.
NaN counts as equal to NaN, so a masked cell staying masked is not a change.
Rows where something moved are shaded, so the eye lands on them.
Wide tables and long file names now stay inside their card.
