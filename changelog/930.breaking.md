Obs4MIPs `instance_id`s are now the identifiers ESGF publishes the datasets under:
the duplicated project prefix and the `nominal_resolution` segment have been dropped
(`obs4MIPs.obs4MIPs.ECMWF.ERA-5.mon.psl.25km.gn.v20251209` becomes `obs4MIPs.ECMWF.ERA-5.mon.psl.gn.v20251209`).
obs4REF keeps a prefix so that a file ingested as both obs4MIPs and obs4REF still gets two distinct identifiers.
Existing obs4MIPs datasets need to be re-ingested, and test case catalogs containing them regenerated with
`ref test-cases fetch --regen`, which also invalidates the regression baselines of the affected test cases.
