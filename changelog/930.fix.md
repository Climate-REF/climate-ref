Fixed CMIP7 conversion of datasets extended past the end of their CMIP6 source
(`extend_historical_to`). The source file is opened chunked, which makes its `time_bnds` a
Dask array of `cftime` objects, and concatenating the repeated years onto it failed with
`Can not use auto rechunking with object dtype`. `repeat_final_year_to` now materialises the
bounds first.

A converted CMIP7 file's `tracking_id` is now derived from the file being written rather
than minted at random.

`ref test-cases fetch` now rewrites a test case's catalog whenever its content would change,
rather than only when the datasets it selects change. The hash stored in the catalog
identifies that selection and deliberately ignores the metadata recorded for each dataset,
so a metadata-only change -- a new field, or a corrected value -- was silently not written
without `--force`.
