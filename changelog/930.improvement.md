Fetching test data for a test case that already has a catalog now resolves the datasets that catalog records,
by searching ESGF for their `instance_id`s rather than re-running the facet search each request declares.

CMIP7 requests are the exception: their data is converted from CMIP6 locally, and a recorded
CMIP7 dataset names neither an id ESGF knows nor the CMIP6 dataset it came from. They keep
re-resolving their declared facets until CMIP7 data is published for real.
