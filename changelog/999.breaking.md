Reworked the results reader filters to improve their consistency.

- `ExecutionsReader.statistics` and `select_execution_statistics` now take a `DiagnosticFilter` instead of slug and `input_datasets` keyword arguments.
- Removed `DiagnosticsReader.stats`, which duplicated `ExecutionsReader.statistics`. Use `reader.executions.statistics` instead.
- `ResourcesReader.profiles` no longer takes `diagnostic_contains`, `provider_contains` or `since`. Pass a `ResourceFilter` instead.
- `ResourceFilter.since` is replaced by `created_after`.
- `ResourceFilter` now keeps only the promoted diagnostic version by default, like the other filters. Pass `include_superseded=True` for every version.
- `input_datasets` on group-level readers (`ExecutionsReader.groups`, `DiagnosticsReader.list`, the statistics) now checks each group's latest execution rather than any execution in the group. `InputDatasetFilter.execution_group_clause` changes the same way.
- Removed `MetricValueFilter(promoted_only=...)`, `ExecutionGroupFilter(facets=...)` and the `facet_filters` argument of `get_execution_group_and_latest_filtered`. Use `include_superseded` and `selectors`.
- Moved every results query builder into `climate_ref.results.queries`, so the readers and other callers such as ref-app build the same queries. `select_datasets` is no longer importable from `climate_ref.results.datasets`, and `climate_ref.results._query.count_values` is now `climate_ref.results.queries.count`.
- Added `select_execution_groups` and `select_execution_group_ids`, which take an `ExecutionGroupFilter`. `filter_by_selectors` applies `selectors`, which the database query cannot.
- Removed `get_execution_group_and_latest`, `get_execution_group_and_latest_filtered`, `query_execution_group_and_latest_filtered` and `count_execution_group_and_latest_filtered` from `climate_ref.models.execution`. Use `select_execution_groups` or `ExecutionsReader.group_rows` instead.
- Replaced `latest_execution_for_group(session, id)` with the builder `select_latest_execution(id)`.
- Moved `Reader` into `climate_ref.results.reader`. `from climate_ref.results import Reader` is unchanged.
- `latest_only` moves from `ExecutionScope` onto `MetricValueFilter` and `ResourceFilter`, the only filters that pick among a group's executions.
- `ExecutionsReader.groups`, `ExecutionsReader.statistics` and `DiagnosticsReader.list` now drop a group whose latest execution is retracted, as `latest_only` already did for values. Pass `include_retracted=True` to keep it.
- `DiagnosticView.execution_group_count` now counts only groups at the promoted version by default. Pass `include_superseded=True` for every version.
- `DiagnosticView.total` now counts executions, every rerun included, rather than execution groups.
- `DiagnosticsReader.with_values` and `select_diagnostics_with_values` no longer take `scope`. Set `include_retracted`, `created_after` or `created_before` on the `DiagnosticFilter` instead.
